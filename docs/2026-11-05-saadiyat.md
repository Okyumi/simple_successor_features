We test whether readout-space alignment improves Simple SF sample efficiency.
The loss adds lambda times the mean twin-head centered/normalized projection
residual to the original TD loss; lambda=0 retains upstream parameter updates.

Added `agent/nrc2.py`, `agent/sf_nrc2.py`, its Hydra config, geometry diagnostics,
and tests; repaired the missing video import, unused torchvision import, Hydra
launcher configuration, and JSONL logging. Added `experiment_configs.py` for
editable grids, frozen JSON manifests, indexed execution, and collision checks;
`hpc/` provides setup, environment, submission, and one-GPU Slurm array scripts.
The cluster settings follow Okyumi/sgcrl section3_done DRAFT_jubail.sh.

Launch: `bash hpc/setup_saadiyat.sh`, then
`bash hpc/submit_saadiyat.sh --stage smoke`, then `--stage pilot`.
See EXPERIMENTS.md for exact hyperparameter overrides and output paths.
Logged metrics include return, TD loss, NRC2 loss, feature variance/rank99,
readout rank/condition, plus resolved configurations and installed packages.

Validation: nine tests pass; all 88 preset configurations compose with Hydra;
shell syntax checks pass; the indexed manifest runner completed a real CPU
Walker smoke run. CUDA, cluster module availability, scheduler execution,
pixels and full training sweeps remain unverified. No HPC job was submitted.
This is a penultimate-feature test on the original architecture, not an early
residual-block reproduction. No measured performance gain is claimed.
