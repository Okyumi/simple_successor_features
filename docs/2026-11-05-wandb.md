# W&B experiment tracking

The experiment grid disabled W&B and upstream initialization forced offline mode. New non-smoke grids now enable it, use environment-configurable project/entity/mode, name runs with the NRC2 coefficient and target, and group by stage. Metrics use train/frame and eval/frame as their respective axes. No losses, optimizer settings, or training schedules changed.

Use EXPERIMENTS.md for authentication and submission commands. scripts/upload_wandb.py imports completed JSONL runs without restarting existing jobs; it previews by default and requires --upload to send data. Imports cannot recover unlogged metrics or historical system telemetry. Do not update a checkout used by queued jobs.

Validation: existing unit tests, local offline W&B smoke run, and synthetic JSONL import tests. Online authentication and compute-node network access must be checked on Jubail with a W&B-enabled smoke run.
